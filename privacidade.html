Política de Privacidade — Contador Publicador

Última atualização: 28 de outubro de 2026.

O que é o app

O Contador Publicador é uma ferramenta de uso interno do canal O Contador de Histórias. Ela envia e agenda vídeos no canal do próprio dono, usando a API de Dados do YouTube (YouTube API Services). Não é oferecida ao público.

Quais dados acessamos

  • Permissão para enviar vídeos e gerenciar os vídeos, miniaturas, títulos e descrições do canal autorizado.
  • Informações básicas do canal (nome e ID), só para confirmar que o canal certo está conectado.

Não acessamos dados de espectadores, comentários de terceiros, e-mails, contatos ou qualquer outra informação da conta Google.

Como usamos e guardamos

O token de acesso fica salvo apenas no computador do dono do canal, que executa a ferramenta. Ele é usado somente para publicar os vídeos do próprio canal. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Serviços do Google e do YouTube

Esta ferramenta usa os YouTube API Services. Ao usá-la, você também concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google: security.google.com/settings/security/permissions. Ao revogar, o token salvo deixa de funcionar.
